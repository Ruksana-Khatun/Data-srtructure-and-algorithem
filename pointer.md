## DSA Development Roadmap

### Goal
Build strong problem-solving skills with data structures and algorithms, then apply them consistently in coding interviews, competitive programming, and real projects.

### Phase 1: Foundations
Start with the basics and get comfortable with writing clean code.

- Time complexity and space complexity
- Variables, loops, functions, recursion basics
- Arrays and strings
- Input/output and debugging
- Basic sorting and searching

### Phase 2: Core Data Structures
Learn how each structure works, when to use it, and how to implement it.

- Arrays and dynamic arrays
- Linked lists
- Stacks and queues
- Hash maps and hash sets
- Trees and binary trees
- Binary search trees
- Heaps and priority queues
- Graphs

### Phase 3: Core Algorithms
Focus on the patterns that appear again and again in DSA problems.

- Binary search
- Two pointers
- Sliding window
- Prefix sums
- Recursion and backtracking
- Divide and conquer
- Greedy algorithms
- Dynamic programming
- Graph traversal: BFS and DFS
- Shortest path basics

### Phase 4: Problem-Solving Patterns
Instead of memorizing solutions, learn the patterns behind them.

- Frequency counting
- Fast and slow pointers
- Monotonic stack
- Intervals and merging
- Subarray and subsequence problems
- Tree recursion
- Connected components
- Topological sorting

### Phase 5: Practice Plan
Use a repeatable routine every day.

1. Solve 1 easy problem to warm up.
2. Solve 1 medium problem on a focused topic.
3. Review mistakes and write the pattern used.
4. Re-solve old problems after 2 to 3 days.
5. Track weak topics and revise them weekly.

### 12-Week Study Plan

#### Weeks 1-2
- Big-O notation
- Arrays and strings
- Basic sorting and searching
- Recursion basics

#### Weeks 3-4
- Linked lists
- Stacks and queues
- Hash maps and sets
- Two pointers and sliding window

#### Weeks 5-6
- Trees
- Binary search trees
- Heap and priority queue
- Tree traversal problems

#### Weeks 7-8
- Graph basics
- BFS and DFS
- Connected components
- Topological sort

#### Weeks 9-10
- Dynamic programming basics
- 1D DP
- 2D DP
- Memoization and tabulation

#### Weeks 11-12
- Greedy algorithms
- Backtracking
- Mixed revision
- Timed problem practice

### Daily Routine

- 20 minutes: revise notes and patterns
- 40 minutes: learn one concept
- 60 to 90 minutes: solve problems
- 15 minutes: write what you learned

### What To Track

- Problems solved per topic
- Repeated mistakes
- Topics that take too long
- Patterns you recognize quickly

### Recommended Order

1. Arrays and strings
2. Hashing
3. Two pointers
4. Sliding window
5. Recursion
6. Linked list
7. Stack and queue
8. Trees
9. Graphs
10. Dynamic programming

### Tips

- Focus on understanding, not memorizing.
- Write code by hand first if needed.
- Explain each solution in simple words.
- Practice consistently instead of cramming.
- Review mistakes more than new problems.

### Simple Rule
If a topic feels hard, break it into smaller patterns and solve 3 to 5 problems before moving on.
